# C# Windows Forms: Vehicle Rental Manager

This repository contains the source code for a project I worked on managing vehicle rentals. It demonstrates how to build a basic graphical user interface and apply Object-Oriented Programming (OOP) concepts in C#.

**📺 Watch the full tutorial here:** (https://www.youtube.com/@CodedByVin).

## Features
* Enter and save customer details, vehicle registration, type, and rental days.
* The app prevents saving if any information is left blank.
* Calculates the total cost for you based on the chosen vehicle type and number of days.
* Displays all active rentals instantly on the main screen.
* Click on any rental to open a summary window, and update its details.
* Save your list to a file so you don't lose your work when you close the app.

## Tech Stack
* **Language:** C#
* **Framework:** .NET Framework (Windows Forms)
* **IDE:** Visual Studio

## How to Run This Code
1. Click the green **Code** button and download the ZIP file, or clone the repository.
2. Extract the folder and open the `.sln` (Solution) file using Visual Studio.
3. Ensure you have the **.NET desktop development** workload installed.
4. Press **Start** (or `F5`) in Visual Studio to run the application.
